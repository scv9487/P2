# P2 — 가챠 트레이너즈

**가챠 트레이너즈**는 매판 초기화되는 로그라이크 게임으로 개발합니다. 가챠 트레이너가 다양한 가챠에서 크리쳐와 특성 수정(패시브 스킬 부여)을 뽑고 최대 3마리의 파티를 구성하여, 실시간 전투와 상금 및/또는 유물 획득을 반복하는 게임입니다.

## 게임 실행

Unity **6000.0.58f2**에서 [Title.unity](Assets/0_Project/GachaTrainers/Scenes/Title.unity)를 열어 Play하고 시작 버튼을 누르세요. 상점에서 크리쳐를 한 마리 이상 뽑은 뒤 **아레나 입장**으로 전투를 시작합니다.

- **WASD**: 상점 캐릭터 이동
- **E**: 가까운 가챠 머신 이용
- **마우스**: 유료 뽑기, 파티 선택·방출, 수정 장착·해제
- **Esc**: 창 닫기 / 창이 없으면 타이틀 복귀 확인

전투는 양측에서 한 마리씩 출전하고 기절하면 다음 크리쳐가 자동 소환됩니다. **총 10개 스테이지**이며 단계마다 적 편성이 달라집니다. 1스테이지 상대는 잿불여우·이끼거북·번개토끼입니다. 가챠에서는 이 3종과 **서리올빼미·물결수달·바위멧돼지**를 획득할 수 있습니다. 6종 모두 바라보는 8방향에서 대기·이동·회피·피격·기본 공격·고유 스킬 애니메이션이 재생됩니다.

- **WASD**: 출전 크리쳐 이동
- **좌클릭 길게 누르기 / 우클릭 / Space**: 기본 공격 / 고유 스킬 / 회피
- **Tab / 모드 버튼**: 직접 조작 ↔ 자동 전투
- **1·2·3 / 아군 파티 버튼**: 생존한 크리쳐로 즉시 교체
- **Esc**: 전투 일시정지·재개

1~9스테이지 승리 후 상금 **200 G**를 받고 같은 파티로 상점에 돌아와 다음 단계에 도전합니다. **10스테이지 승리 시 모험 완료 후 타이틀**로 돌아갑니다. 패배·무승부·전투 포기도 런을 끝냅니다. 빠르게 전투만 확인하려면 새 Play 세션에서 [Battle.unity](Assets/0_Project/GachaTrainers/Scenes/Battle.unity)를 직접 열면 아군도 기본 3종으로 시작합니다.

밸런싱은 **[GachaStageTable.csv](Assets/1_InternalTools/Util/DataSheetLoader/Table/GachaStageTable.csv)**를 수정하세요. 물공·마공·생명력 배율은 현재 `0.5 → 0.7 → … → 2.3`(매 단계 +20%p), 적 배열은 `EmberFox|MossTurtle|VoltRabbit`처럼 입력합니다. 각 열과 스테이지를 독립적으로 수정할 수 있으며 저장·임포트 후 다시 Play하면 반영됩니다. 영문 종 ID·편집 예시는 [시트 사용법](Docs/Planning/07_StagesAndBalanceSheet.md)에 있습니다.

**초기 금화·뽑기 가격·매 단계 금화 보상·가챠 확률**은 [GachaEconomyTable.csv](Assets/1_InternalTools/Util/DataSheetLoader/Table/GachaEconomyTable.csv)의 `Values` 열을 수정합니다. `Economy.VictoryGold`는 `200|200|…`처럼 1~10단계 순서의 배열입니다. 크리쳐·스킬·수정·진화·공통 전투 수치도 별도 CSV로 옮겼으며, 파일 목록과 수정 예시는 [전체 밸런스 시트 안내](Docs/Planning/08_BalanceTables.md)에 정리했습니다. 숫자 시트 변경은 새 모험부터 적용되며 가격표·확률·스킬 설명도 함께 반영됩니다.

자동 전투에서도 출전 크리쳐를 직접 선택할 수 있습니다. 수동 교체는 체력·쿨다운·기존 투사체를 유지하며, 모드 선택은 같은 런의 다음 전투에도 이어집니다.

새 런은 **600 G**로 시작합니다. 크리쳐 **100 G**, 수정 **60 G**이며 모두 **일반 50% / 고급 30% / 희귀 15% / 전설 5%**입니다. 기본 크리쳐는 등급별 **3/2/1/0종**입니다. 전설 0종의 예약 구간은 현재 교환할 대상이 없는 **전설 선택권**으로 보관하는 임시 정책입니다. 수정은 DS 각인을 바탕으로 **12종**입니다.

**B / 보관함**에서 보유 유닛을 관리하고 최대 3마리를 출전시킵니다. 소유 수에는 제한이 없습니다. 같은 형태 3마리를 모으면 **A/B 선택 진화**, 랭크는 1~3이며 희귀도는 유지됩니다. 기본 6종에서 총 42개 형태로 나뉩니다. 보관함에 물리·마법 공격력, 저항, 치명타·가드·흡혈 등 **최종 능력치 22개**를 표시합니다.

직접 조작의 기본 공격·스킬은 **마우스 방향**으로 발사합니다. 기본 공격은 물리, 스킬은 마법 피해이며 스킬은 기력 25를 사용합니다. 2:2 및 5초 직접 개입은 검토안으로 문서에 정리했습니다. 새 런에서는 보유 개체·진화·돈·수정·선택권을 초기화합니다.

## 기존 기반 테스트 씬

DS/IZ에서 가져온 입력·요청 처리·데이터·UI·저장 기반은 [2_Test.unity](Assets/0_Project/2_Test/0_Scenes/2_Test.unity)를 열어 Play하면 확인할 수 있습니다.

- F1 / F2: 숫자 증가 / 감소
- 이름 입력 → 이름 적용: 문자열 데이터 변경
- F5 / F9: 저장 / 불러오기
- Esc: 팝업 열기 / 닫기
- 현재 데이터 초기화: 메모리만 초기화하고 저장 파일 유지

저장 파일 위치는 화면 하단에 표시됩니다. 문자 편집 중에는 단축키가 차단됩니다.
