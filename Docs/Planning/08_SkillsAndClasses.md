# 무기·직업·스킬

## 사용자 요구

- 무기 종류로 직업을 구분하고, 직업마다 하나의 액티브 트리만 사용한다.
- 레벨 필요 경험치, 레벨업 시 얻는 스킬 포인트, 스킬 내용·수치는 DS를 기준으로 한다. P2에 맞지 않는 스킬은 제외한다.
- 패시브는 직업 제한 없이 전체 목록에서 선택한다. 플레이어는 직접 선택해서 습득한다.
- NPC는 레벨업 때 무작위로 습득하되, 현재 배울 수 있는 스킬 중 최소 요구 레벨이 높은 스킬을 우선한다.
- 마을·던전 좌측 하단 자신의 초상화 옆 가방·스킬 버튼으로 팝업을 연다.
- 이 기능 역시 [핵심 기획 방향](00_GameDirection.md)의 모험가 생활·관계 중심, 기획 수치와 문구의 데이터 시트 분리 원칙을 따른다.

## 적용 사양

- DS와 같이 액티브(Main)·패시브(Sub) 포인트를 구분한다. 초기 지급은 각각 10·6, 레벨업마다 각각 6을 얻는다. 필요 경험치와 레벨 상한은 기존 DS 성장 시트를 유지한다.
- 습득하려면 현재 직업의 액티브 트리 또는 공용 패시브에 속하고, 요구 레벨·남은 포인트·선행 스킬 조건을 모두 충족해야 한다. 중복 습득은 불가하다.
- NPC는 레벨업과 같은 저장 작업에서 포인트를 받고, 배울 수 있는 후보의 최고 요구 레벨 집합 중 무작위 하나를 구매한다. 조건을 다시 계산하며 더 배울 수 없을 때까지 반복한다. 플레이어는 자동 구매하지 않는다.
- 검·대검·둔기·활·화염 지팡이·물 지팡이·자연 지팡이·방패·창의 9직업을 정의한다. `CharacterClassTable.csv`는 초기 배정이며 [장비 교체](09_EquipmentAndItems.md) 후 현재 직업은 장착 무기로 결정한다.
- 활·물·자연 액티브의 원본은 공간·소환 의존성이 높아 현재 구매 가능한 액티브가 없다. 해당 직업도 기본 공격과 모든 공용 패시브를 사용할 수 있으며 UI에 빈 액티브 목록 사유를 표시한다.
- 패시브의 **습득 자격**은 모든 직업에 열려 있으나, 효과에 붙은 조건은 유지한다. 예를 들어 방패 장착 시 공격속도 증가나 자연 지팡이의 기본 공격 변경은 해당 무기가 있어야 발동한다.
- 가방은 개인 소지품의 수량·정가·금화 확인과 [무기 장착·포션 사용](09_EquipmentAndItems.md)을 제공한다. 탐험 공동 전리품은 정산 전까지 개인 소지품에 포함하지 않는다. 거래는 기존 상점, 탐험 아이템 구매는 기존 정산에서 진행한다.
- 메뉴를 연 동안 전투 시간과 배경 입력을 멈춘다. 플레이어는 자신의 준비된 차례에 기본 공격 또는 배운 액티브를 선택하고 대상을 확정한다. 동료는 가능한 액티브를 자동 선택하고, 없으면 기본 공격한다.
- 스킬은 DS의 계수·기력 비용·재사용 대기시간·조건부 효과를 적용한다. 기력은 탐험 시작 시 최대치로 시작하고, 전투가 흐르는 동안 원본의 자연 증감이 적용된다. 사용 가능한 행동은 기존 행동 게이지 규칙을 따른다.
- 카드 전투의 광역은 해당 진영 카드 집합으로 판정한다. `AllUnits`인 익스플로전은 아군도 피해를 받는다. 지면 위치·거리·이동·소환이 핵심인 스킬과 DS에서 구현되지 않은 항목은 제외한다. 원본과의 대응 및 제외 근거는 [DS 이식 근거](../Architecture/SkillsDS.md)에 기록한다.

## 저장과 기존 진행

- 저장 버전 5는 인물별 잔여 Main/Sub 포인트, 습득 ID, 학습 후 기본 공격 처치 누적을 원천으로 보관한다. 시트에서 스킬 가격이 바뀌어도 과거 비용을 다시 차감하지 않는다.
- 기존 버전 1~4 저장은 로드 시 현재 레벨에 해당하는 누적 포인트를 부여한다. 불러오기 자체가 파일을 다시 쓰거나 NPC의 스킬을 무작위 선택하지 않는다. 기존 NPC는 다음 실제 레벨업 시 자동 습득한다.
- 포인트 지출과 습득 ID를 저장한 뒤에만 화면과 전투 능력치에 확정 반영한다. 실패 시 재시도가 가능하고, 손상된 저장은 덮어쓰지 않는다.

## 기획 데이터

`Assets/1_InternalTools/Util/DataSheetLoader/Table/`의 다음 CSV가 원천이다.

- `SkillDefinitionTable.csv`: 학습 스킬·기본기, 이름·설명, 트리, 요구 레벨·선행·비용, 계수·기력·대기시간·대상.
- `SkillClassTable.csv`, `SkillWeaponTable.csv`, `CharacterClassTable.csv`: 직업과 무기·기본 공격·인물 배정.
- `SkillSettingTable.csv`: SP 지급, 기력·공통 대기시간, 상태이상·중첩 설정.
- `SkillTextTable.csv`: 가방·스킬·전투 선택 UI 문구.
- `CharacterLevelTable.csv`, `CharacterGrowthTable.csv`, `CharacterGrowthSettingTable.csv`: 기존 DS 경험치·주요 능력치 성장.

회복·보호막·가드·기절·연소 등의 효과는 실제 전투 상태에 적용한다. 추가타·광역·반격 처치도 기존 경험치·쥐 꼬리·의뢰 진척 경로로 전달한다.
