# 전투 조작 선택과 각인 수정 이식

> 현재 변경: 보유 한도·등급별 확률·진화·최종 전투 능력치·마우스 조준은 [2026-11-25 확장 사양](06_CollectionEvolutionAndCombatStats.md)이 우선한다. 아래 초기 사양과 구분한다.

2026-11-24 후속 요청을 [핵심 기획](00_GachaTrainers.md)에 추가한다. 이 문서는 초기의 단순 능력치 수정 3종과 고정 직접 조작 규칙을 대체하는 변경 사항을 설명한다.

## 사용자 명시 요구

- 아군 크리쳐를 직접 조작할지 자동 전투하게 할지 선택할 수 있어야 한다.
- 기본 공격은 마우스 좌클릭, 스킬은 우클릭, 회피는 Space로 변경한다.
- 플레이어가 원할 때 출전 크리쳐를 교체할 수 있어야 한다.
- 구매 가능한 수정은 단순 능력치 증가 대신 **던전 세틀러즈의 각인 중 가챠 트레이너즈에서 사용할 만한 효과**를 이식한다.
- 수정에 희귀도 등급을 적용한다.

## 조작 선택의 보완 사양

- 새 런의 기본 선택은 직접 조작이다. `RunDataContainer.AutoBattle`에 선택을 기록하여 같은 런의 다음 전투에서도 유지한다. 타이틀에서 새 런을 시작하면 초기화한다.
- 전투 중에도 선택을 변경할 수 있다. 자동 전투 모드에서의 이동·공격·스킬·회피는 AI가 수행하며, 출전 크리쳐 선택은 플레이어가 제어한다.
- 직접 조작 시 이동은 기존 WASD, 기본 공격은 좌클릭 유지, 고유 스킬은 우클릭, 회피는 Space를 사용한다. 상세한 입력·교체 제한과 상태 처리는 [전투 기획](03_RealTimeBattle.md)과 [게임 구조](../Architecture/GachaTrainers.md)에 기록한다.

## 이식 대상과 수치 차이

아래 6종 선택, 재조정한 수치, 확률은 구현 보완 사양이다. 희귀도는 DS의 해당 각인 등급을 유지한다. 이번 선택에는 Common 각인이 없으며, 일반 능력치 수정을 채우기 위해 추가하지 않는다.

| P2 수정 / DS 원본 ID | DS 희귀도 | DS 원본 효과·수치 | P2 적용 효과·수치 |
| --- | --- | --- | --- |
| 불씨 / `AFFECTER_EmberInscription` | 고급(Uncommon) | 기본 공격 3회마다 6초 동안 연소 2중첩 부여 | 기본 공격 3회 명중마다 4초 동안 초당 3의 연소 피해. 단순 공격력 증가가 아닌 누적 명중 발동 |
| 보호 / `AFFECTER_ProtectionInscription` | 희귀(Rare) | 전투 진입 시 잃은 생명력의 200% 보호막을 20초 동안 부여. 재발동 60초 | 출전 시 잃은 체력의 50% 보호막을 5초 동안 부여. 재발동 12초. 최대 체력이면 보호막이 0이므로 재발동 시간을 소모하지 않음 |

### 전투 판정의 보완 사양

- 불씨·침몰의 기본 공격 명중 횟수는 투사체가 실제 상대에게 닿았을 때 증가한다. 회피 무적에 막힌 타격은 세지 않으며, 보호막이 피해를 전부 흡수한 타격은 센다. 횟수는 크리쳐마다 보유하고 교체해도 유지한다.
- 발악은 발사 시 공격자의 체력 비율, 침몰은 명중 시 대상의 체력 비율로 계산한다. 사형은 해당 직접 공격의 체력 피해를 적용한 뒤 남은 체력을 확인한다.
- 연소는 4초 동안 1초마다 기본 피해 3을 준다. 연소 중 다시 적용되면 남은 시간만 4초로 갱신하고 다음 피해 틱까지의 시간은 유지한다. 대기 중에는 연소 시간과 틱이 경과하지만 피해는 받지 않는다. 따라서 다시 출전해도 지나간 틱의 피해가 한꺼번에 적용되지 않는다.
- 반사는 보호막 흡수 후 실제로 잃은 체력의 25%를 원래 투사체 발사자에게 돌려준다. 그 발사자가 교체되어 대기 중이어도 반사 피해를 받는다. 현재 출전한 다른 크리쳐에게 피해를 넘기지 않는다. 한 시뮬레이션 간격의 직접 타격을 모두 처리한 뒤 반사를 적용하여 같은 간격의 양측 전멸을 판정한다.
- 연소·반사 피해는 회피 무적을 무시하지만 보호 수정의 보호막과 이끼거북 방어 스킬의 피해 50% 감소를 적용받는다. 이 피해는 불씨·침몰 명중 수, 반사, 사형 등 다른 각인 발동을 연쇄적으로 유발하지 않는다.
- 보호의 재발동 시간은 크리쳐마다 유지되고 대기 중에도 경과한다. 교체 자체로 재사용 시간이나 남은 보호막 시간을 초기화하지 않으며, 재발동 가능 상태로 다시 출전했을 때만 새 보호막을 부여한다.

## 구매·희귀도·장착

- 수정 머신 가격은 **60 G**, 새 런 자금은 **600 G**를 유지한다. 기존 생명·힘·신속 수정은 구매 목록과 런 데이터에서 제거한다. 크리쳐 기본 체력·공격력·공격 속도는 장착만으로 변하지 않고 실제 패시브 효과는 전투에서 처리한다.
- 수정 종류별 희귀도는 고정이다. 한 종류에 여러 등급의 별도 아이템을 만들지 않는다. 같은 수정 중복 획득은 기존 재고 수량으로 쌓인다.
- 크리쳐당 수정 슬롯 1개, 교체·해제·방출 시 원래 수정 반환, 실패 시 돈·재고 보존 규칙을 유지한다. 전투 중 수정 장착·해제는 허용하지 않는다.
- 구입 시 한 번의 정수 추첨으로 결과를 결정한다. 범위는 0 이상 400 미만이며, 유효하지 않은 결과는 차감 전에 거절한다.

| 수정 | 가중치 / 400 | 개별 획득 확률 | 추첨 구간 |
| --- | ---: | ---: | --- |
| 불씨 | 280 | 70% | 0~279 |
| 보호 | 25 | 6.25% | 280~304 |
| 반사 | 25 | 6.25% | 305~329 |
| 발악 | 25 | 6.25% | 330~354 |
| 침몰 | 25 | 6.25% | 355~379 |
| 사형 | 20 | 5% | 380~399 |

등급별 총확률은 고급 **70%**, 희귀 **25%**, 전설 **5%**다. 이름과 색상뿐 아니라 등급명·효과·획득 확률을 화면에서 확인할 수 있게 한다. `GachaCatalog.GetCrystalForRoll`, `GetCrystalRollStart`, `GetCrystalDropPercent`, `GetRarityName`을 같은 카탈로그 기준으로 사용하여 표시와 추첨을 일치시킨다.

## 검증

구매와 효과·입력·교체의 검증 결과는 [게임 구조와 검증 기록](../Architecture/GachaTrainers.md)에 실행 이후 기록한다. 원본 효과 수치와 P2에서 보완한 효과 수치를 혼동하지 않는다.
