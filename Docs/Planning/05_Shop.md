# 상점 거래

기획 기준은 [핵심 방향](00_GameDirection.md)과 [전리품·금화·소지품](04_LootAndSettlement.md)이다.

## 사용자 명시 요구

- 상점에서 아이템을 거래할 수 있다.
- 화면 좌측에는 플레이어 인벤토리, 우측에는 상인 인벤토리를 표시한다.
- 상인은 생명력 포션을 판매한다.

## 이번 구현의 보완 사양

- 시장과 주점의 기존 ‘거래’ 커맨드로 상점창을 연다. 두 장소의 상인은 각각 독립된 재고를 가진다.
- 상인별 초기 재고는 생명력 포션 10개, 정가는 20금화다. 아이템 정가는 LootItemTable, 상인과 장소·초기 재고·문구는 Shop CSV에서 조정한다.
- 좌측의 보유 아이템을 고르면 판매, 우측의 상인 아이템을 고르면 구매를 준비한다. 수량을 조절하고 단가·총액·거래 후 내 금화를 확인한 뒤 해당 거래를 확정한다.
- 현재 매입가와 판매가는 모두 아이템 정가다. 할인·흥정·수수료·상인의 금화 한도는 이번 단계에서 적용하지 않는다.
- 구매하면 상인 재고가 줄고 내 소지품이 늘어난다. 판매하면 내 소지품이 줄고 해당 상인의 재고에 들어가므로 같은 상점에서 다시 구매할 수 있다.
- 금화 부족, 보유량·상인 재고 초과, 수량 0 이하, 금액·수량 범위 초과는 확정할 수 없다.
- 거래 한 건을 확정할 때 금화·플레이어 아이템·상인 재고를 함께 저장한다. 저장 성공 뒤에만 화면에 반영한다. 저장 실패 시 기존 상태를 유지하여 재시도할 수 있으며, 같은 확인 입력을 두 번 받아도 중복 거래하지 않는다.
- 거래를 마친 뒤에도 상점은 열려 있어 다음 물품을 선택할 수 있다. 닫기 또는 Esc는 현재 장소로 돌아간다. 이미 확정한 거래는 취소하지 않는다.
- 상점이 열린 동안 뒤쪽 장소 커맨드·인물·마을 이동 입력은 차단한다. 예전에 열린 상점이나 이전 선택에서 늦게 들어온 거래 입력도 거절한다.
- 재고는 상점 재진입·씬 이동·게임 재실행 뒤에도 유지하며 방문마다 자동으로 채우지 않는다. 새 진행 데이터와 아직 저장되지 않은 새 상인의 초기 재고에만 시트 값을 사용한다.
- 기존 전리품 정산 저장의 금화·보유 아이템·정산 기록은 유지한다. 이후 [장비·아이템 사용](09_EquipmentAndItems.md)에서 9종 무기 거래와 가방의 장착·포션 사용을 연결했다. 장착품 1개는 판매할 수 없고 여분만 판매할 수 있다.

구조·저장·검증은 [상점 구조](../Architecture/Shop.md)를 따른다.
