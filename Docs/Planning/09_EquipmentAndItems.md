# 장비와 아이템 사용

기획 기준은 [핵심 방향](00_GameDirection.md), [무기·직업·스킬](08_SkillsAndClasses.md), [상점](05_Shop.md)이다.

## 사용자 명시 요구

- 가방에서 무기를 장착하거나 교체한다.
- 무기에 따라 직업과 사용할 수 있는 액티브 스킬이 바뀐다.
- 상점에서도 무기를 거래한다.
- 가방에서 생명력 포션을 사용한다.

## 구현 시 보완한 사양

- 검·대검·둔기·활·화염 지팡이·물 지팡이·자연 지팡이·방패·창을 하나씩 제공한다. 아이템 ID와 무기 종류를 분리하여 같은 종류의 다른 무기도 추가할 수 있다.
- 플레이어는 검 1개를 소유·장착한 상태로 시작한다. NPC는 기존 직업에 맞는 개인 무기를 가지고 있으며 플레이어 가방에 포함하지 않는다. 이번 장착 조작 대상은 플레이어다.
- 가방의 아이템을 고르면 수량·정가와 효과를 확인하고 장착/사용한다. 장착품 1개도 보유 수량에 포함한다. 교체한 이전 무기는 가방에 남고, 같은 무기를 다시 장착하면 소모나 행동을 발생시키지 않는다.
- 무기를 바꿔도 습득 스킬·SP를 유지한다. 현재 무기 직업의 액티브만 배우거나 사용할 수 있고, 원래 무기로 돌아오면 기존 액티브를 다시 쓸 수 있다. 패시브는 모두 보유하며 효과에 붙은 무기 조건을 다시 평가한다.
- 무기별 기본 공격·주기는 기존 DS 대응 시트를 따른다. 이번 아이템에는 별도 공격력 보너스나 내구도·등급을 추가하지 않는다. 활·물·자연 직업의 구매 가능한 액티브가 없는 이유는 기존 [스킬 기획](08_SkillsAndClasses.md)을 따른다.
- 시장과 주점은 각각 9종의 무기를 3개씩 판매한다. 가격은 50~90금화의 P2 임시 기획값이며 정가로 매입·판매한다. 장착 중인 1개는 판매 불가하고 여분은 판매할 수 있다. 교체하면 이전 무기도 판매 가능하다.
- 생명력 포션은 플레이어 자신의 생명력 100을 회복한다. 이는 시트의 기본 회복량이고 기존 회복 관련 패시브가 있으면 그 효과도 적용한다. 최대 생명력을 넘지 않으며, 이미 가득 찼거나 쓰러진 경우 소모하지 않는다. 부활·동료 대상 사용은 제공하지 않는다.
- 전투 중에는 자기 행동 게이지가 찬 차례에 장착/포션 사용이 가능하고 한 번의 행동을 소비한다. 성공하면 가방이 닫히고 전투가 이어진다. 다른 차례에도 가방을 열어 살펴볼 수 있지만 행동은 실행할 수 없다. 전투 밖에서는 행동 게이지 비용이 없다.
- 가방을 연 동안 배경 입력과 전투 시간을 정지한다. 장비 교체로 현재 HP·기력·쿨다운을 초기화하지 않는다. 최대치가 낮아지면 현재량을 최대치로 제한한다.
- 기존의 마을/새 탐험 완전 회복 정책을 유지한다. 마을에서는 HP가 가득 찬 상태이므로 포션을 소모하지 않는다. 탐험 중 HP·게이지·쿨다운을 재실행 후 복원하는 기능은 이번 범위에 포함하지 않는다.
- 장착 변경과 포션 수량 차감을 저장한 뒤 적용한다. 저장 실패 시 장비·아이템·HP·행동 게이지를 유지하며 재시도할 수 있다. 중복·오래된 선택 요청은 다시 실행하지 않는다.

## 저장과 시트

- 진행 저장 v6은 인물별 장착 아이템 ID와 아이템 행동 처리 ID를 추가한다. v1~5 저장은 메모리에서 시작 장비와 부족한 신규 무기 재고를 이행하고 다음 성공한 저장 때 반영한다. 기존 금화·소지품·상인 포션·판매품·관계·성장·의뢰·스킬 원천은 유지한다.
- 초기화가 끝난 상점은 품절되어도 다시 채우지 않는다. 파일이 손상되면 쓰기를 막는다.
- `EquipmentDefinitionTable.csv`: 아이템→무기 종류. `CharacterEquipmentTable.csv`: 시작 무기. `ConsumableDefinitionTable.csv`: 회복 효과·양. `EquipmentTextTable.csv`: 가방·장비·사용 문구.
- 가격·이름은 `LootItemTable.csv`, 재고는 `ShopStockTable.csv`, 무기별 직업·기본기·스킬은 기존 Skill CSV를 사용한다. 변경한 시트는 다음 씬 초기화 때 읽는다.
