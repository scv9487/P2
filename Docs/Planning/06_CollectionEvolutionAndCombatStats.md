# 보유 유닛·선택 진화·희귀도·최종 전투 능력치

2026-11-25 후속 요청. 이 문서의 보유·확률·조준 규칙이 02~05 문서의 초기 사양보다 우선한다.

- 소유 가능한 유닛 수를 출전 인원과 분리하여 확대한다.
- 직접 조작의 공격 방향은 마우스 방향을 사용한다.
- 크리쳐와 수정 모두 일반/고급/희귀/전설을 사용하고 등급별 추첨 확률은 50/30/15/5%다.
- 기본 크리쳐 6종의 등급별 종류 수는 3/2/1/0이다.
- DS의 각인을 추가 이식하고 최종 전투 능력치를 확인하여 도입한다.
- 동일 크리쳐 3마리로 다음 랭크로 진화한다. 랭크는 1~3이며 희귀도는 변하지 않는다. 진화할 때 A/B 중 하나를 선택한다.
- 2:2 등 전투 방식 확대, 직접 조작 시간·자원 제한, 5초 직접 조작 스킬, 개입 타이밍의 전략성은 **검토 요청**이다.

## 구현 보완 사양

### 보유와 편성

보유 수에는 제한을 두지 않는다. 보관함은 8마리씩 페이지로 보여주고 출전 파티는 최대 3마리를 유지한다. 처음 빈 출전 슬롯은 구매한 크리쳐로 자동 채운다. 이후 구매는 보관함에 추가한다. B 또는 상점의 보관함 버튼으로 보유 개체를 선택하고 출전 1/2/3 슬롯에 편성한다. 기존 출전 개체를 다른 슬롯에 배치하면 순서를 교환한다. 출전 해제는 보유 개체를 유지한다. 방출은 개체를 제거하고 장착 수정을 반환하며 돈을 환급하지 않는다.

보관 중인 크리쳐에도 수정을 장착할 수 있다. 전투에 들어간 후에는 편성·진화·구매·장착·방출을 변경할 수 없다. 새 런은 돈·보유 개체·진화·수정·선택권·조작 모드를 초기화한다. 전투 승리 후 상점 복귀는 같은 런이므로 이를 유지한다.

### 희귀도와 추첨

| 등급 | 확률 | 기본 크리쳐 | 수정 종류 수 |
| --- | ---: | --- | ---: |
| 일반 | 50% | 잿불여우, 이끼거북, 번개토끼 | 3 |
| 고급 | 30% | 서리올빼미, 물결수달 | 3 |
| 희귀 | 15% | 바위멧돼지 | 5 |
| 전설 | 5% | 현재 0종 | 1 |

같은 등급 안에서는 동일 확률이다. 크리쳐는 정수 구간 600개 중 일반 각 100, 고급 각 90, 희귀 90, 전설 예약 30을 사용한다. 수정은 1200개 구간 중 일반 각 200, 고급 각 120, 희귀 각 36, 전설 60을 사용한다. 따라서 수정 종류가 늘어도 등급 확률을 혼동하지 않는다. 확률은 보관함 구성이나 현재 파티에 따라 바뀌지 않는다.

**전설 0종과 5%의 충돌은 사용자에게 선택권 보관 / 전설 추가 / 재분배를 질문했다. 답변 전 임시 보완은 ‘전설 선택권 보관’이다.** 이 구간에서는 다른 등급 크리쳐를 대신 주지 않고 전설 선택권을 1장 기록한다. 구매창과 보관함에 현재 전설이 0종임을 명시한다. 현재 교환 가능한 대상이나 교환 기능은 없으며 선택권도 런 종료 시 초기화된다. 이는 사용자가 확정한 전설 콘텐츠가 아니다. 후속 답변에 따라 바꿀 수 있다.

### 선택형 진화

- 기본 6종 각각 `기본 → A/B → AA/AB/BA/BB`의 이진 계통, 총 **42개 형태**다. 랭크별로 6 / 12 / 24개다.
- 재료는 **같은 기본 종·같은 랭크·같은 진화 경로**의 3마리다. 서로 다른 A/B 계통은 합성되지 않는다. 랭크 3은 더 진화하지 않는다. 랭크 3 한 마리는 기본형 9마리가 필요하다.
- 구매로 진화 가능한 조합이 생기면 선택창을 연다. 나중에 선택할 수 있고 보관함의 진화 버튼으로 다시 연다. 보관함에서 선택한 개체가 진화 가능하면 그 개체를 기준으로, 아니면 첫 가능한 조합을 제시한다.
- A/B 선택을 확정할 때 재료 3마리를 원자적으로 제거하고 1마리를 만든다. 선택 전에는 재료·돈·수정을 소비하지 않는다. 기준 개체의 수정과 식별자를 유지하고 나머지 2마리의 수정은 모두 반환한다.
- 재료가 출전 중이었다면 가장 앞선 해당 출전 슬롯을 진화체가 이어받는다. 남은 파티 개체와 보유 개체는 보존한다. UI 중복 클릭이나 잘못된 분기 번호는 추가 재료를 소비하지 않는다.
- 희귀도는 기본 종에 속한다. 일반 크리쳐의 랭크 3도 일반이다. 진화체는 가챠의 기본 종 수에 포함하지 않는다.

도입한 최종 능력치는 **최대 체력, 물리 공격력, 마법 공격력, 공격 속도, 치명타율, 치명타 추가 피해, 재사용 감소, 명중, 회피, 가드, 가드 피해 감소, 흡혈, 주는 피해, 받는 피해, 물리 피해 보너스, 마법 피해 보너스, 물리 저항, 마법 저항, 이동 속도, 최대 체력 비율 재생, 최대 기력, 기력 재생**의 22개다. 모두 실제 전투 계산에 연결했다. 생존·생활·작업·시야·경험치·부위별 체력·주요 능력치는 현재 전투 시스템에 대응하는 기능이 없어 이식 대상에서 제외했다.

- 기본 공격은 물리 공격력/물리 저항, 고유 스킬 투사체는 마법 공격력/마법 저항을 사용한다. 랭크 1의 물리·마법 공격력은 기존 공격 수치와 같다.
- 투사체의 기하학적 충돌 후 `명중 - 회피`를 판정한다. 회피 무적도 명중을 막는다. 가드를 먼저 판정하고 가드가 아닐 때 치명타를 판정한다.
- 피해 보너스는 DS처럼 `1 + (주는 피해 + 해당 속성 피해 + 받는 피해)/100`, 저항 배율은 `100/(100+저항)`이다. 가드 배율은 `1-가드 피해 감소/100`, 치명타 배율은 `1+치명타 추가 피해/100`이다. 이후 수호·철벽·보호막과 체력 손실을 처리한다.
- 기본 공격 간격은 `1/공격 속도`, 스킬 쿨다운은 DS처럼 `기본 시간/(1+재사용 감소/100)`이다. 기본 기력 100, 스킬 비용 25, 초당 재생 5를 적용한다. 기력이 부족하면 수동·자동 모두 스킬을 쓰지 않는다.
- 주는/받는/속성 피해 보너스는 직접 투사체 계산에 적용한다. 연소·반사는 기존의 고정 피해 기준과 수호·철벽·보호막 처리를 유지하며, 마격 추가 피해에는 별도 마법 저항을 적용한다.
- 흡혈은 직접 공격으로 실제 잃게 한 체력만 기준으로 한다. 과잉 피해·처형분·보호막 흡수·파생 피해는 포함하지 않고 죽은 발사자를 부활시키지 않는다.
- 기본 치명타·회피·가드·저항·재생은 0, 명중 100, 치명타 추가 피해 50%, 가드 피해 감소 50%다. 진화와 조건형 수정이 관련 역할을 만든다. 모든 수치는 구현 보완 사양이다.
- 비활성 파티원의 쿨다운과 상태 지속 시간은 흐르지만 체력·기력 재생은 출전 중에만 진행한다. 일시정지·포커스 상실·소환 대기 중에는 전투 수치를 진행하지 않는다.
- 전투마다 소유 개체의 종·진화 경로·수정으로 불변 최종 능력치를 계산한다. View가 스탯을 수정하지 않는다. 확률 판정은 모델에 주입 가능한 난수 함수로 테스트한다.

광대·부싯돌·탄성의 확률 보정은 초기형에서도 해당 발동 조건을 사용할 수 있게 한 P2 보완이다. DS의 무작위 약화·부위 체력·장비 내구도·전체 Affecter 프레임워크는 가져오지 않는다. 연소·반사·마격 피해가 다른 각인이나 흡혈을 재귀 호출하지 않는다.

### 직접 조작 조준

마우스를 카메라의 월드 좌표로 변환하여 Input 요청에 담는다. EventQueue에서 모델의 조준점을 갱신하고 이동·발사 후에도 그 지점을 바라본다. 왼쪽 클릭 기본 공격과 오른쪽 클릭 스킬은 동일 조준 방향을 사용한다. 자동 모드는 상대 위치를 추적한다. UI 버튼 또는 레터박스 위의 클릭은 전투 공격을 생성하지 않는다. 잘못된 좌표와 포커스 상실·일시정지 입력은 무시한다. 화면에는 조준 표시를 둔다.

## 검토 결과와 후속 구현안

### 2:2 전투

기본 출전 파티 3마리를 유지하면서 동시에 2마리가 싸우고 1마리가 예비인 시험 모드를 권장한다. 한 마리만 직접 조작하고 나머지는 AI로 움직이며, 조작 대상 변경과 예비 교체를 구분해야 한다. 구현 시 `Player/Enemy` 단일 활성 참조, 투사체의 단일 대상 충돌, AI 타겟 선정, 팀별 위치 분리, 전체 팀 전멸 판정, HUD를 함께 바꿔야 한다. 다중 대상 각인(폭풍·충격파)은 이 단계에서 이식하는 편이 적절하다. 현재 플레이 가능한 방식은 1:1이며 상대 기본 3종을 유지했다.

### 시간 제한 직접 개입

추천 시험 규칙은 **기본 자동 → 개입 키를 누르면 5초 직접 조작 → 자동 복귀**, 공유 재충전 20초, 보유 충전 1회다. 조작 대상 교체로 남은 시간을 새로 받지 않고 전투 일시정지는 개입 시간도 멈춘다. 기절 시 남은 개입은 종료한다. 궁극기 회피, 빙결창 방향 지정, 수달 회복과 교체 시점에 개입 가치를 만들 수 있다. 쿨다운 방식은 이해하기 쉽고, 초당 자원 소모 방식은 세밀한 개입이 가능하지만 UI와 밸런싱 비용이 커진다.

이 수치와 기본 모드 변경은 아직 확정 요구가 아니므로 이번 런타임에는 적용하지 않았다. 현재는 직접/자동 자유 전환이며 새 기력은 **크리쳐 스킬 비용**에 사용한다. 검토안을 채택할 때 직접 조작 자원과 스킬 기력을 혼동하지 않도록 별도 계기로 표시한다.

## 검증

확률 전 구간, 보유/출전 분리, A/B 계통·랭크 한계, 수정 보존, 전투 중 변경 거절, 최종 능력치 계산, 추가 각인, 조준 입력과 씬 UI는 회귀 테스트로 유지한다. 실제 실행 결과는 [게임 구조](../Architecture/GachaTrainers.md)에 기록한다.
