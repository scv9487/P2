# 타이틀·가챠샵 씬

> 현재 변경: 보유 한도·등급별 확률·진화·최종 전투 능력치·마우스 조준은 [2026-11-25 확장 사양](06_CollectionEvolutionAndCombatStats.md)이 우선한다. 아래 초기 사양과 구분한다.

2026-11-24 요청을 기준으로 [핵심 게임 기획](00_GachaTrainers.md)의 첫 플레이 구간을 구현한다. 사용자 명시 요구와 이번 구현에서 보완한 사양을 구분한다.

이 문서의 전투 제외 범위는 초기 타이틀·상점 구축 당시의 범위다. 이후 추가된 상점의 전투 시작 버튼, 실시간 전투, 승리 보상·상점 복귀는 [실시간 전투 기획](03_RealTimeBattle.md)을 따른다.

아래 생명·힘·신속 수정 3종과 각 1/3 확률은 초기 구현 기록이다. 후속 요청으로 구매 가능한 수정은 [각인 수정 6종과 희귀도별 확률](04_ControlAndEngravings.md)로 대체되었다. 가격 60 G, 크리쳐당 슬롯 1개, 수정 반환 규칙은 유지한다.

크리쳐도 후속 요청으로 [총 6종·각 1/6 확률](05_CreatureExpansion.md)로 확장되었다. 아래 크리쳐 3종 표와 확률은 초기 기록이며, 가격 100 G와 최대 파티 3마리는 유지한다.

## 사용자 명시 요구

- 게임의 씬 구성은 **타이틀 씬 / 가챠샵 씬 / 전투 씬**이다.
- 이번 구현 대상은 **타이틀 씬과 가챠샵 씬**이다.
- 가챠샵에서는 캐릭터를 **WASD로 조작**하여 배치된 가챠 머신과 상호작용한다.
- 상호작용 시 **돈을 지불하고 새로운 크리쳐 또는 특성 수정**을 얻는다.
- 머신은 **크리쳐 머신 1종과 수정 머신 1종**을 구현한다.
- 뽑기 콘텐츠는 **크리쳐 3종과 수정 3종**이며, 종류별 세부 기획은 구현자가 정한다.
- 기존 핵심 기획의 **최대 3마리 파티**, **수정을 통한 패시브 스킬 부여**, **매판 초기화**를 유지한다.

특성 수정은 초기 기획의 “특성 결정”과 같은 개념이다. 이번 화면과 문서에서는 “특성 수정” 또는 “수정”으로 표기한다.

## 구현 시 보완한 사양

### 씬과 조작

| 상황 | 조작과 동작 |
| --- | --- |
| 타이틀 | 시작 버튼으로 새 런을 만들고 가챠샵으로 이동. 종료 버튼은 Player 종료 또는 Editor Play 종료 |
| 가챠샵 이동 | WASD. 대각선 속도 보정, 상점 경계와 머신 충돌 영역 적용 |
| 머신 상호작용 | 머신 앞에 가까이 다가가 E. 가까운 머신 강조와 이용 안내 표시 |
| 뽑기 | 머신 창에서 마우스로 구매 버튼 선택. 가격·가능한 결과·각 1/3 확률 표시 |
| 파티 관리 | 마우스로 크리쳐 선택, 선택한 크리쳐 방출, 수정 장착·해제 |
| 창 닫기 | Esc 또는 닫기 버튼 |
| 타이틀 복귀 | 상점에서 Esc 또는 타이틀 버튼으로 복귀 확인 창을 열고 확인. 취소하면 런 유지 |

머신 창과 타이틀 복귀 창이 열리면 캐릭터 이동과 배경 파티 조작을 막는다. 앱 포커스를 잃을 때 수집한 입력을 비우며, 다시 포커스를 얻기 전에는 게임 입력을 실행하지 않는다.

### 초기 자금과 뽑기

| 항목 | 이번 구현값 |
| --- | --- |
| 새 런 초기 자금 | 600 G |
| 초기 파티 / 수정 | 빈 파티 / 수정 없음 |
| 크리쳐 뽑기 | 100 G, 아래 크리쳐 중 하나를 각 1/3 확률로 획득 |
| 수정 뽑기 | 60 G, 아래 수정 중 하나를 각 1/3 확률로 획득 |
| 중복 | 같은 종류의 크리쳐와 수정 모두 중복 획득 가능 |
| 파티 합류 | 획득한 크리쳐는 빈 파티 슬롯에 자동 합류하며 새 크리쳐를 선택 |
| 파티가 가득 찬 경우 | 크리쳐 뽑기 거절. 추첨·차감하지 않으며, 선택한 크리쳐를 방출해 자리를 만들 수 있음 |
| 돈이 부족한 경우 | 추첨·차감·아이템 변경 없이 거절 |
| 크리쳐 방출 | 돈 환급 없음. 장착 수정은 보관함에 반환 |

위 가격과 확률은 초기 플레이를 위한 구현값이며 사용자 확정 요구가 아니다. 상금·유물과 전투 보상으로 돈을 다시 얻는 흐름은 전투 구현 시 연결한다.

### 크리쳐 3종

| 종류 | 역할 / 인상 | 최대 체력 | 공격력 | 초당 공격 횟수 |
| --- | --- | ---: | ---: | ---: |
| 잿불여우 | 작은 몸에 뜨거운 한 방을 품은 공격수 | 85 | 18 | 0.9 |
| 이끼거북 | 단단한 등껍질과 넉넉한 체력의 수호자 | 150 | 9 | 0.7 |
| 번개토끼 | 번개처럼 재빠르게 공격하는 속공수 | 75 | 10 | 1.5 |

능력치는 파티 화면에 표시한다. 현재 전투 시뮬레이션은 구현 범위에 포함하지 않는다.

### 특성 수정 3종

| 종류 | 장착 시 패시브 효과 |
| --- | --- |
| 생명 수정 | 최대 체력 +50 |
| 힘 수정 | 공격력 +5 |
| 신속 수정 | 공격 속도 +20% |

- 크리쳐 한 마리당 수정 슬롯은 1개다. 파티에서 크리쳐를 선택한 뒤 보유 수정 버튼을 눌러 장착한다.
- 장착한 수정은 보관함 수량에서 1개 빠지며, 해당 크리쳐의 계산된 능력치에 효과를 적용한다.
- 다른 수정으로 교체하면 이전 수정을 보관함에 반환한다. 해제 또는 크리쳐 방출 시에도 장착 수정을 반환한다.
- 같은 수정 재장착, 수정 재고 없음, 선택 크리쳐 없음 등 실패 시 수정이나 돈을 소모하지 않는다.
- 장착·교체·해제에는 추가 비용이 없다.

### 런 수명과 구현 범위

타이틀에서 시작하는 새 런은 돈·파티·수정을 초기화한다. 타이틀 복귀 확인 후에도 이전 런을 끝낸다. 실행을 종료했다가 이어 하는 저장·불러오기는 이번 게임 흐름에 포함하지 않는다. 기존 기반 테스트 씬의 저장 기능은 별도 테스트 기능으로 유지한다.

전투 씬은 전체 게임 구성에 포함된 후속 개발 대상이다. 이번에는 타이틀·가챠샵을 구현하며 전투, 전투 결과, 상금·유물 지급을 구현했다고 취급하지 않는다.
