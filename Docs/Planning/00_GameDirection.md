# P2 핵심 기획 방향

기준일: 2026-11-21

P2의 기획과 개발에서 지속적으로 참고할 기준 문서다. 아래 세 가지는 사용자가 명시한 방향이며, 개별 기능의 설계와 우선순위를 판단할 때 적용한다.

## 사용자 명시 방향

### 1. 모험가의 인생을 살아가는 게임

P2는 플레이어가 모험가의 인생을 살아가는 게임이다.

### 2. 다양한 모험가와의 관계에서 생기는 경험에 집중

P2는 던전 RPG다. 이 게임이 차별화하고 집중하려는 것은 **다양한 모험가와 상호작용하며 관계를 쌓는 과정**, 그리고 **그 관계에서 발생하는 다양한 경험**이다.

### 3. 기획으로 조정할 수치와 문자열은 데이터 시트로 분리

기획적으로 변경될 수 있는 수치 및 문자열 데이터는 별도의 데이터 시트에 두고, 시트에서 값을 조절할 수 있도록 한다.

## 앞으로의 작업에 적용하는 기준

다음은 위 방향을 작업에 적용하기 위한 보완 기준이다.

- P2 작업을 시작할 때 이 문서를 읽고, 기획·기능 설계·구현·리뷰의 기준으로 삼는다.
- 게임 기능을 설계하거나 우선순위를 정할 때 모험가로 살아가는 경험, 다른 모험가와의 상호작용, 관계 형성과 그로부터 생기는 경험에 어떻게 기여하는지 점검한다.
- 기능에 필요한 수치와 문자열 중 기획 조정 대상을 식별하고, 해당 값은 코드에 직접 고정하지 않고 시트에서 읽도록 구성한다. 기능 문서에는 사용하는 시트와 항목을 기록한다.
- 시트가 제공하는 설정·콘텐츠 값과 플레이 중 변하는 상태·저장 데이터의 역할을 구분한다. 시트 반영 시점은 해당 기능의 사양에 명시한다.
- 후속 사용자 요청으로 핵심 방향이 변경되면 이 문서와 관련 기능 문서를 함께 갱신한다.

## 현재 구현과 미정 사항

현재 구현 범위는 [타이틀·마을](02_TitleAndTown.md), [던전 탐험과 전투](03_Dungeon.md), [기반 테스트 씬](01_Foundation.md)에 기록되어 있다. 마을과 던전의 조정 가능한 콘텐츠·수치·문구는 CSV에서 읽는다.

[전리품·정산·금화·소지품](04_LootAndSettlement.md)은 별도 시트와 진행 저장으로 관리한다. 구체적인 관계 시스템, 성장, 시트 편집 도구와 실행 중 반영 방식은 해당 기능의 기획에서 정한다.

[상점 거래](05_Shop.md)는 플레이어와 상인의 인벤토리 사이에서 아이템과 금화를 교환하며, 상인 재고까지 진행 저장에 포함한다.

[인물과 파티](06_CharactersAndParty.md)는 친밀도에 따른 영입, 최대 4인 동행, DS 기반 전투 능력치와 성장을 연결한다. 향후 관계 요소 확장은 이 원천 데이터와 상호작용 경로를 기준으로 한다.

[길드 의뢰](07_Quests.md)는 던전 클리어·아이템 납부·모험가 구조·몬스터 처치를 수주하고 길드에 보고하는 활동이다. 의뢰 상태는 기존 모험 진행과 함께 저장한다.

[직업과 스킬](08_SkillsAndClasses.md)은 DS 기반 성장·학습과 개인 메뉴를 연결한다. [장비와 아이템 사용](09_EquipmentAndItems.md)은 장착 무기로 직업을 정하고 상점 거래·가방의 교체 및 포션 사용을 제공한다.
