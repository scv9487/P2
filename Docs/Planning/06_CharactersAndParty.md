# 인물과 파티

기준일: 2026-11-21. [핵심 방향](00_GameDirection.md)의 관계 중심 플레이를 실제 친밀도·영입·동행으로 연결한다.

## 사용자 명시 요구

- 인물은 이름, 성별, 나이, 전투 능력치, 레벨, 경험치, 친밀도를 가진다.
- 전투 수치 관리·수식·기본값과 동작은 DS를 참고하여 동일하게 구현한다. 레벨업 때 6종 주요 능력치는 DS의 보통 재능 기준으로 무작위 상승한다.
- 경험치가 최대가 되면 자동으로 레벨이 오른다. 대화를 선택하면 친밀도가 오른다.
- 장소의 인물 카드에는 대화하기·영입하기가 있다. 현재 영입 수락 확률은 친밀도만 영향을 주며 0에서 0%, 100에서 100%다.
- 파티는 최대 4명이다. 마을과 던전 하단에 파티 카드가 있고, 선택하여 대화하거나 추방할 수 있다.
- 인물 6명이 주점에 항상 등장한다. 영입한 대상은 주점이나 다른 장소의 방문자로 중복 등장하지 않는다.

## 이번 구현의 보완 사양

- 파티 정원은 플레이어를 포함한 4명이다. 플레이어는 추방할 수 없고 자신의 카드에서는 정보만 확인한다.
- 새 진행과 기존 인물 데이터가 없는 저장의 최초 이행은 플레이어 혼자 시작한다. 이전 임시 전투 파티의 미라는 자동 영입하지 않는다. 기존 금화·아이템·상인 재고·정산 기록은 유지한다.
- 주점의 인물은 미라, 오린, 브란, 세라, 네리, 카스다. 기존 네 초상화를 사용하며 네리·카스는 기존 초상화를 재사용한다. 이름·성별·나이·초기 주요 능력치 등은 시트로 조정한다.
- 초기 친밀도는 0, 대화 1회당 기본 +10이며 100에서 멈춘다. 대화·영입 시도·추방을 저장에 성공한 뒤 반영한다. 거절된 영입 시도도 기록하여 같은 입력의 중복 판정을 막는다.
- 영입 수락은 정수 난수 0~99가 친밀도보다 작은지 검사한다. 정원이 찼으면 영입할 수 없고 이미 동료인 대상은 다시 영입하지 않는다.
- 추방하면 즉시 활성 파티에서 빠진다. 해당 인물의 친밀도·경험치·성장 수치·금화는 남고, 다시 주점 등 지정 장소에서 만날 수 있다. 던전 안에서 재합류해도 같은 탐험에서 남아 있던 체력을 유지한다.
- 마을과 던전의 인물 상세에는 기본 정보, 레벨/경험치, 친밀도, 6종 주요 능력치와 DS 파생 전투 수치를 표시한다. 방문자는 대화·영입, 동료는 대화·추방을 제공한다.
- 인물 상세가 열린 동안 전투의 시간 진행과 뒤쪽 명령을 멈춘다. 전투 중 아군 카드도 상세를 열며, 직접 공격 선택은 기존처럼 플레이어의 행동 대기 때만 제공한다.

## 전투와 성장

- 주요 능력치는 힘·맷집·의지·지능·민첩·지각이며 기본은 각각 10이다. 최대 레벨 12, 레벨별 필요 경험치와 보통 재능 상승 범위는 DS 원본에서 옮긴 시트를 사용한다.
- DS의 수동 레벨업/제물 선택 절차는 사용자 요구에 따라 경험치 충족 시 즉시 자동 성장으로 바꾼다. 제물 없는 배율 1을 사용한다. 초과 경험치를 버리고 성장 뒤 0으로 만드는 DS 방식은 유지한다. 누적 성장량을 저장하고 불러올 때 현재 인물 시트의 기본값에 합산한다. 기본값 변경은 기존 인물에도 적용되며, 확정된 성장 난수는 다시 뽑지 않는다.
- 플레이어와 동료는 현재 장비가 없으므로 DS 맨손 기본 공격의 물리 계수 0.3, 기본 주기 0.6초를 사용한다. 실제 주기는 기본 주기 / 공격 속도다. 회색쥐는 DS 원본의 기본 전투 수치와 물리 계수 1, 기본 주기 1초를 사용한다.
- 기존 P2의 카드·행동 게이지·플레이어만 수동 선택하는 방식은 유지한다. DS의 시작/종료 애니메이션 지연 합계를 한 번의 게이지 주기로 표시한다. 별도 월드 이동·BT·장비·스킬 선택·상태 이상 콘텐츠는 이번 인물 기반에 추가하지 않는다.
- 명중/회피 → 물리 가드 → 치명타의 판정 순서, 물리/마법 저항, 피해 보정과 흡혈 계산은 DS를 따른다. 체력과 피해는 소수 값을 유지한다. 레벨업에 따른 최대 체력 증가가 현재 체력을 자동 회복시키지는 않는다.
- 던전 1의 1층 일반 회색쥐가 DS 원형이다. 던전 번호·층·보스 강도는 기존 Dungeon 시트의 기준 대비 비율로 보정한다.
- 회색쥐 처치 경험치 8을 처치 시점의 활성 파티 인원으로 나누고 인물별 경험치 획득 보정을 적용한다. DS처럼 전투 영역에 남은 쓰러진 동료도 분배 대상이다. 처치마다 저장·성장하며 같은 처치의 보상을 중복 지급하지 않는다.
- 경험치 저장 실패는 전투와 진행을 멈추고 안내 창의 닫기로 재시도한다. 재시도에서 성장 난수를 다시 뽑지 않는다.
- 필요 경험치 시트를 낮추어 기존 저장 경험치가 새 상한을 넘으면, DS처럼 불러올 때 현재 상한으로 제한한다. 불러오기만으로 성장 난수를 추첨하거나 파일을 덮어쓰지 않으며, 다음 경험치 지급 때 자동 레벨업한다.

## 기존 전리품과의 연결

- 전리품 정산은 이번 탐험에 실제 참가한 인물을 기준으로 한다. 도중 영입한 동료를 추가하고 추방한 참가자의 몫도 남겨, 추방으로 이미 함께 얻은 보상을 빼앗지 않는다.
- 각 인물의 `LootWeight`가 합의 비율의 기본값이며 현재는 모두 1이다. 2명은 50:50, 4명은 25%씩이다. 정수 비율과 잔여 금화는 기존 최대 나머지 방식으로 배분한다.

## 조정 시트

모든 시트는 `Assets/1_InternalTools/Util/DataSheetLoader/Table/`에 있다.

| 시트 | 내용 |
| --- | --- |
| TownCharacterTable / TownLocationTable | 이름·역할·초상화·대사, 주점 및 장소 방문자 |
| CharacterDefinitionTable | 성별·나이·플레이어 구분·기초 6능력치·초기 친밀도·전리품 가중치 |
| CharacterSettingTable / CharacterTextTable | 파티 정원·대화 상승량·플레이어 초상화, 상호작용 문구 |
| CharacterGrowthTable / CharacterLevelTable / CharacterGrowthSettingTable | 보통 재능 성장·레벨별 경험치·성장 설정 |
| CombatStatTable / CombatEnemyTable / CombatAttackTable | DS 파생 수식·기본값, 회색쥐 원형, 기본 공격 계수·주기 |

DS 원본 근거와 정확한 계산은 [DS 전투·성장 이식](../Architecture/CharactersCombatDS.md), 실행과 저장은 [인물·파티 구조](../Architecture/CharactersAndParty.md)를 따른다.
