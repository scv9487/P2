# 실시간 전투 씬

> 현재 변경: 보유 한도·등급별 확률·진화·최종 전투 능력치·마우스 조준은 [2026-11-25 확장 사양](06_CollectionEvolutionAndCombatStats.md)이 우선한다. 아래 초기 사양과 구분한다.

2026-11-24 요청을 기준으로 타이틀 → 가챠샵 → 전투 → 상점 복귀 흐름을 연결한다. [핵심 게임 기획](00_GachaTrainers.md)의 최대 3마리 파티와 매판 초기화를 유지한다.

## 사용자 명시 요구

- 전투 씬을 구현한다.
- **Big Kid Nation의 Pokémon Arena 2D**처럼 크리쳐들이 **실시간으로 전투**하는 방식을 참고한다.
- 테스트 상대는 현재 게임의 **기본 크리쳐 3종**을 사용한다.
- 양측에서 **한 마리씩 소환하여 싸우는 방식**으로 시작한다.
- 크리쳐가 바라보는 **8방향에 따라 스프라이트가 달라지도록** 한다.
- 크리쳐 스프라이트에 **대기·이동·회피·피격·스킬 사용 등 동작 애니메이션**을 적용한다.
- 직접 조작 / 자동 전투 선택, 좌클릭 기본 공격·우클릭 스킬·Space 회피와 수동 크리쳐 교체를 지원한다. 수정은 [DS 각인 이식·희귀도 사양](04_ControlAndEngravings.md)을 따른다.
- [크리쳐 3종 추가](05_CreatureExpansion.md)에 따라 서리올빼미·물결수달·바위멧돼지도 출전할 수 있다. 테스트 상대는 기본 3종을 유지한다.

참고 범위는 실시간 아레나 전투다. [제작자 게임 소개](https://www.bigkidnation.com/games)와 [공식 프로젝트 사이트](https://www.pokemonarena2d.com/)에서 실시간 픽셀 아트 아레나 전투를 확인했다. 제작자는 조작 방식이 아직 발표되지 않았다고 안내하므로, 아래 키 배치·전투 수치·스킬은 가챠 트레이너즈의 구현 보완 사양이며 참고 게임의 확정 규칙으로 취급하지 않는다.

## 구현 시 보완한 사양

### 진입과 출전

- 상점의 **아레나 입장** 버튼으로 전투를 시작한다. 파티가 비어 있으면 입장할 수 없다.
- 아군은 상점에서 뽑은 1~3마리를 사용한다. 기본 능력치와 장착한 각인 수정의 종류를 전투 진입 시 복사한다.
- 상대는 **잿불여우 → 이끼거북 → 번개토끼** 순서이며 수정을 장착하지 않은 기본 능력치를 사용한다.
- 처음과 기절 교대 시 약 1초 동안 소환한다. 양측에서 현재 출전 중인 한 마리씩만 이동·공격·투사체 충돌 판정에 참여한다. 이미 발사한 공격의 반사 피해는 교체한 원래 발사자에게 돌아갈 수 있다.
- 한 마리가 쓰러지면 해당 팀의 다음 생존 크리쳐를 자동 소환한다. 기절 교대에서는 남은 투사체를 제거하고 양측을 출발 위치로 되돌리며 살아남은 크리쳐의 남은 체력은 유지한다.
- 전투 진행 중 1·2·3 또는 아군 파티 버튼으로 생존한 다른 크리쳐를 즉시 교체할 수 있다. 수동 교체는 현재 아군 위치를 이어받고 양측 체력·쿨다운·상대 위치·이미 발사한 투사체를 유지한다. 추가 교체 쿨다운·새 무적·회복은 없다. 소환·일시정지·결과 중에는 교체하지 않는다.
- `Battle.unity`를 새 Play 세션에서 직접 열면 아군도 기본 3종을 가진 테스트 런으로 시작한다. 타이틀에서 시작한 정상 런은 빈 파티부터 가챠로 구성한다.

### 조작과 시간

| 조작 | 동작 |
| --- | --- |
| WASD | 현재 아군 크리쳐 이동. 대각선 속도 보정과 아레나 경계 적용 |
| 마우스 좌클릭 길게 누르기 | 기본 공격 반복. 현재 상대를 자동 조준하며 공격 속도에 따른 재사용 시간 적용 |
| 마우스 우클릭 | 크리쳐 고유 스킬 |
| Space | 입력 방향으로 회피. 방향 입력이 없으면 상대 반대 방향으로 회피 |
| Tab / 모드 선택 버튼 | 직접 조작 ↔ 자동 전투. 일시정지 메뉴에서도 선택 가능 |
| 1·2·3 / 아군 파티 버튼 | 생존한 다른 크리쳐로 수동 교체. 자동 전투에서도 사용 가능 |
| Esc | 일시정지 / 재개 |
| 전투 UI 버튼 | 기본 공격 1회, 고유 스킬, 회피, 일시정지·재개, 결과 확인 |

새 런의 기본값은 직접 조작이다. 자동 전투를 선택하면 아군 AI가 거리 조절·횡이동·기본 공격·고유 스킬·위험 투사체 회피를 수행한다. 자동 모드에서는 수동 전투 입력을 받지 않고 모드 선택·크리쳐 교체·일시정지는 허용한다. 선택은 같은 런의 다음 전투에도 유지하며 새 런은 직접 조작으로 돌아간다. UI 버튼 위의 마우스 입력은 전투 공격으로 중복 처리하지 않는다.

회피는 약 0.28초 무적이며 재사용 시간은 3초다. 공격은 사거리와 이동 속도를 가진 투사체로 처리하므로, 발사와 명중 사이에도 양측이 움직일 수 있다. 일시정지 또는 앱 포커스 상실 시 전투 시간·이동·피해·재사용 시간 진행을 멈춘다. 포커스 복귀 후에는 재개 버튼 또는 Esc로 직접 재개한다.

### 크리쳐별 전투 특성

기본 체력·공격력·공격 속도는 [상점 콘텐츠 사양](02_TitleAndGachaShop.md)의 수치를 유지한다.

| 크리쳐 | 기본 공격 | 사거리 | 이동 속도 | 고유 스킬 | 스킬 재사용 |
| --- | --- | ---: | ---: | --- | ---: |
| 잿불여우 | 잿불탄 | 7 | 3.5 | **세 갈래 불꽃:** 전방 3방향에 공격력 115% 불꽃 발사 | 6초 |
| 이끼거북 | 이끼 충격파 | 3.1 | 2.7 | **수호의 파동:** 2.5초간 받는 피해 50% 감소 + 공격력 200%의 큰 파동 | 8초 |
| 번개토끼 | 전기탄 | 6 | 4.2 | **번개 질주:** 짧은 회피 이동 + 공격력 230%의 강화 전기탄 | 5초 |

거리와 속도는 게임 월드 단위다. 수치는 초기 전투 검증용이며 후속 밸런싱 대상이다. 각인 수정 효과는 실제 명중·피해·연소·보호막·처형 처리에 반영한다.

### 8방향 크리쳐 표현

- 잿불여우·이끼거북·번개토끼 모두 **동·북동·북·북서·서·남서·남·남동** 8방향의 전용 스프라이트를 사용한다. 기존 도형 중심의 그림 스타일과 크리쳐별 색상·특징을 유지한다.
- 월드의 위쪽(+Y)을 북쪽으로 보고, 북쪽은 뒷모습, 남쪽은 앞모습, 동·서쪽은 옆모습으로 표현한다. 대각선도 해당 방향을 바라보는 별도 이미지로 표시한다.
- 전투 데이터의 **바라보는 방향**을 가장 가까운 45도 구간으로 나누어 스프라이트를 선택한다. 현재 전투에서는 상대를 조준하는 방향을 바라보므로, 옆걸음·후퇴 중에도 상대를 향한다.
- 바라보는 방향과 이동 입력의 관계는 기존 전투 사양을 유지한다. 방향별 그림 교체와 함께 소환 확대, 이동 흔들림, 피격·회피·보호막 연출을 적용한다.

### 동작 애니메이션

- 총 6종의 8방향 모두 대기·이동·회피·피격·기본 공격·고유 스킬의 6동작을 사용한다. 동작마다 실제 스프라이트 4프레임을 연결하여 총 1152프레임으로 표현한다. 기본 공격 포함, 프레임 수와 재생 시간은 구현 보완 사양이다.
- 대기는 호흡·귀·꼬리·눈 깜박임, 이동은 교차하는 발과 몸의 들썩임, 회피는 낮춘 자세와 잔상, 피격은 움찔과 눈 감기로 구분한다.
- 고유 스킬은 잿불여우의 불꽃 발사, 이끼거북의 머리 숨기기·방어, 번개토끼의 귀 충전·도약으로 구분한다.
- 대기 1.2초와 이동 0.4초는 반복한다. 회피 0.28초, 피격 0.16초, 기본 공격 0.28초, 고유 스킬 0.5초는 동작 발생 시 시작하는 단발 애니메이션이다.
- 동시에 발생하면 피격 → 고유 스킬 → 회피 → 기본 공격 → 이동 → 대기 순으로 표시한다. 번개토끼 스킬에 포함된 회피 중에도 스킬 동작을 볼 수 있다. 피격 표시가 끝나면 남아 있는 동작의 진행 시점으로 복귀한다.
- 모델의 실제 이동량과 승인된 공격·스킬·회피·피해 처리로 상태를 바꾼다. 멈추거나 벽에 막혀 움직이지 않으면 이동 반복을 끝낸다. 같은 액션의 재발동은 해당 애니메이션을 처음부터 시작한다.
- 애니메이션은 전투 시간으로 진행하여 일시정지·포커스 상실·결과 화면에서 멈춘다. 소환 중에는 대기 첫 프레임과 기존 소환 확대를 표시하고, 교대·재전투 시 이전 동작 시간을 초기화한다.
- 기존 이동 속도·공격 재사용 시간·투사체 발사 시점·피해 판정은 유지한다. 애니메이션 때문에 새로운 행동 불가 시간이나 발사 지연을 추가하지 않는다.

### 종료·보상·다음 전투

- 상대가 모두 쓰러지면 승리한다. 결과 화면에서 상점으로 돌아갈 때 **상금 200 G를 한 번만** 지급한다.
- 승리 후 파티·수정·남은 돈을 유지한 채 상점으로 돌아간다. 다음 전투는 모든 출전 크리쳐의 체력을 최대치로 새로 시작한다.
- 아군 전멸은 패배, 양측 마지막 크리쳐의 동시 전멸은 무승부다. 패배·무승부 또는 일시정지 메뉴에서 전투 포기 시 런을 종료하고 타이틀로 돌아간다.
- 결과가 확정되면 전투 시뮬레이션을 멈춘다. 결과 버튼을 중복 실행해도 상금을 다시 받지 않는다.
- 이번 보상은 상금만 구현한다. 유물, 별도 성장·기술 선택, 온라인 대전은 후속 설계 대상이다.
