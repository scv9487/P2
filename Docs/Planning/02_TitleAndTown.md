# 타이틀과 마을

이 문서는 최초 네 장소의 구현 기준이다. 이후 추가한 다섯 번째 장소인 던전 입구와 씬 연결은 [던전 탐험과 전투](03_Dungeon.md)를 따른다.

이후 추가한 마을의 금화·소지품 표시와 모험 진행 저장은 [전리품과 정산](04_LootAndSettlement.md)을 따른다. 아래 초기 구현의 화면 상태·Foundation 저장 범위와 구분한다.

시장·주점의 거래 커맨드는 이후 [상점 거래](05_Shop.md)에서 양쪽 인벤토리와 실제 아이템 매매로 확장했다.

## 사용자 명시 요구

- 전체 게임은 타이틀 씬, 마을 씬, 던전 씬으로 구성한다. 이번 구현 범위는 타이틀과 마을이다.
- 마을은 게임의 중심 배경이다. 장소를 선택하면 해당 장소의 팝업/화면으로 전환하고 장소별 조작을 제공한다.
- 장소 커맨드는 화면 좌측, 방문 인물 초상화는 화면 상단에 나열한다. 인물을 선택하여 대화하는 흐름을 제공한다.
- 주점: 거래, 소문, 나가기.
- 시장: 거래, 나가기.
- 여관: 휴식, 나가기.
- 길드: 의뢰 수주, 의뢰 완료.
- [핵심 기획 방향](00_GameDirection.md)에 따라 기획 수치와 문자열은 시트에서 조정한다.

## 구현 시 보완한 사양

아래는 초기 마을 구현의 범위다. 이후 길드의 의뢰 수주·완료는 [실제 의뢰 진행과 보고](07_Quests.md)로 연결했다.

- `1_Title` → `2_Town`을 실제 Unity 씬으로 연결한다. 네 장소는 마을 씬 안의 화면 상태로 전환한다. 기존 `2_Test` 씬은 별도로 유지한다.
- 각 씬을 직접 Play할 수 있다. MainFlow는 씬별로 생성/해제하며 타이틀 복귀 후 다시 입장하면 마을의 화면 선택 상태가 초기화된다.
- 이번 단계는 장소/커맨드별 팝업과 인물 선택·대화 흐름을 구현한다. 거래 가격, 휴식 효과, 의뢰 조건·보상과 관계 수치는 후속 기능 기획에서 정한다.
- 장소명, 설명, 커맨드 목록, 방문 인물 목록, 인물 이름·소개·대사, UI 문구는 CSV로 분리한다. 인물과 대사는 화면 흐름을 확인하기 위한 예시이며 확정된 세계관 설정이 아니다.
- 모든 장소에 공통 `마을로 돌아가기` 버튼을 둔다. 길드의 장소 커맨드는 요청한 두 개를 유지하면서 공통 버튼으로 나갈 수 있다.
- Esc는 세부 팝업 → 장소 화면 → 마을 전경 순서로 한 단계씩 닫는다. 마을 전경에서는 아무 동작도 하지 않는다. 타이틀에서 선택된 버튼이 없으면 Enter로 마을에 진입하고, 버튼이 선택되어 있으면 해당 버튼을 실행한다.
- 세부 팝업이 열린 동안 뒤쪽 장소 커맨드와 인물 선택은 차단한다. 요청에 출발 장소 ID를 담고 처리 시 현재 장소와 다시 비교한다.
- 전환 중 입력을 잠그고 보류 요청을 비운다. 타이틀과 마을에서는 기존 기반 테스트용 F1/F2/F5/F9 동작을 실행하지 않는다.
- 현재 마을 데이터는 화면 선택 상태다. 디스크 저장 대상은 기존 Foundation 테스트 데이터로 유지한다. 실제 인물 관계·소지품·의뢰 상태가 추가될 때 저장 범위를 함께 정의한다.
- 배경과 초상화는 교체 가능한 프로젝트 에셋으로 구성한다. 이미지의 배치와 시트의 인물/장소 연결을 분리한다.

## 설계 카드

| 항목 | 결정 |
| --- | --- |
| 입력 | TitleMenuView/TownView → UIInputStream → InputBinding → TownActionRequested |
| 실행 | MainFlow.Update의 중앙 EventQueue → TownEventHandler |
| 상태 | TownDataContainer가 장소/커맨드/대화 대상 선택을 소유; Presenter와 View는 조회 |
| 씬 수명 | MainFlow가 입력·Handler·View 연결을 만들고 씬 언로드 때 해제 |
| 외부 데이터 | TownContent에 CSV/이미지 참조를 연결하고 TownSheet에서 형식·키·참조 검사 |
| 실패 | 현재 장소와 맞지 않는 요청/잘못된 키/모달 뒤 입력 거절; 전환 실패 시 잠금 해제 및 오류 표시 |
| 범위 밖 | 던전 씬, 실제 경제·휴식·퀘스트·관계 시스템, 마을 세이브 |
