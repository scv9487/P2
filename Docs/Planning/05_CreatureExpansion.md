# 크리쳐 3종 추가

> 현재 변경: 보유 한도·등급별 확률·진화·최종 전투 능력치·마우스 조준은 [2026-11-25 확장 사양](06_CollectionEvolutionAndCombatStats.md)이 우선한다. 아래 초기 사양과 구분한다.

2026-11-24 사용자의 **크리쳐 3종 추가** 요청을 기록한다. 기존 잿불여우·이끼거북·번개토끼에 아래 3종을 더해 총 6종으로 확장한다. 이름·외형·역할·능력치·스킬 수치는 구현 보완 사양이다.

## 획득과 파티

- 크리쳐 머신은 100 G로 6종 중 하나를 **각 1/6 확률**로 뽑는다. 중복 획득, 파티가 가득 찼을 때 추첨·차감 거절은 유지한다.
- 최대 파티 인원은 3마리다. 새 크리쳐도 기존 수정 6종을 장착하고 직접/자동 전투와 수동 교체를 사용한다.
- 테스트 상대는 앞선 사용자 요청대로 잿불여우·이끼거북·번개토끼 3종을 유지한다. 직접 전투 씬 실행의 기본 샘플 파티도 이 3종이다. 구매 목록과 테스트 팀 목록을 분리한다.

## 판정과 기존 기능의 관계

- 감속은 중첩하지 않고 지속 시간을 갱신한다. 일반 이동만 느려지며 회피·질주 속도, 공격 속도와 쿨다운은 유지한다. 벤치에서는 시간이 지나고 일시정지 중에는 멈춘다. 교체로 즉시 해제하지 않는다.
- 회피 무적으로 막힌 공격은 피해와 감속·밀치기를 모두 적용하지 않는다. 보호막으로 피해를 전부 흡수해도 명중한 공격의 감속·밀치기는 적용한다. 밀치기는 아레나 경계 안으로 제한하며, 사망한 상대를 다시 이동시키거나 부활시키지 않는다.
- 회복은 최대 체력을 넘지 않고 전투 불능 크리쳐를 부활시키지 않는다. 최대 체력에서도 공격 스킬로 사용할 수 있다. 자동 모드는 공격 범위에 들어왔을 때뿐 아니라 체력이 75% 이하이면 멀리 떨어져 있어도 회복 스킬을 사용할 수 있다.
- 새 투사체도 원래 발사자와 기본/스킬 구분을 보존하므로 불씨·침몰 명중 누적, 발악 피해 배율, 반사와 사형 판정을 공유한다. 고유 스킬 명중을 기본 공격 누적으로 세지 않는다.
- 물결수달은 회복 후 투사체를 발사하므로 발악 피해 배율도 회복 직후 체력으로 고정한다. 사형으로 처형된 상대에는 감속·밀치기를 추가하지 않는다. 반사는 처형분을 제외한 직접 타격의 실제 체력 손실에만 적용하며, 원래 발사자가 벤치에 있어도 귀속을 유지한다.

## 표현과 조작

- 각 종에 8방향 × 6동작(대기·이동·회피·피격·기본 공격·고유 스킬) × 4프레임을 추가한다. 신규 576프레임, 기존 포함 **총 1152프레임**이다.
- 기존 코드로 그린 평면 도형 일러스트 방식과 공통 셀·피벗·배율을 이어 쓴다. 기존 18개 아틀라스와 기존 라이브러리 참조는 유지하고 신규 18개를 추가한다.
- 구매창은 2열 3행으로 6종 이름·확률·특성·스킬 요약을 표시한다. 전투 HUD에는 감속 남은 시간을 표시한다.
- 조작은 [직접/자동 선택·수동 교체 사양](04_ControlAndEngravings.md)을 따른다.
