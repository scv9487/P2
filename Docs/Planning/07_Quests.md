# 길드 의뢰

기획 기준: [핵심 방향](00_GameDirection.md). 길드가 모험가의 활동을 의뢰하고 탐험 성과를 보고받는 흐름을 만든다.

## 사용자 명시 요구

- 길드에서 의뢰를 선택하면 팝업에 네 의뢰가 카드로 표시되고 하나를 선택하여 진행한다.
- 특정 지역의 던전 클리어, 아이템 납부, 모험가 구조, 몬스터 처치 의뢰를 제공한다.
- 구조 의뢰를 진행하면 던전 입장 시 의뢰 노드가 생긴다. 해당 노드의 전투에서 이기면 모험가들을 구출한 것으로 처리한다.
- 몬스터 처치는 회색쥐, 아이템 납부는 쥐 꼬리로 완료할 수 있다.

## 이번 구현의 보완 사양

- 동시에 진행하는 의뢰는 하나다. 카드를 선택해 목표와 보상을 확인하고 수주한다. 네 의뢰는 각각 한 번 완료할 수 있으며 완료 카드는 기록으로 남는다.
- 초기 목표는 던전 1 클리어, 쥐 꼬리 3개 납부, 던전 1의 1층에서 모험가 구조, 회색쥐 3마리 처치다. 목표 지역·수량·보상은 시트로 조절한다.
- 길드의 `의뢰 수주`와 `의뢰 완료`는 같은 게시판을 연다. 진행 중인 의뢰가 있으면 먼저 선택되며, 달성 후 보고 버튼을 누르면 완료와 보상 지급을 확정한다.
- 던전 클리어는 대상 던전의 마지막 층 보스를 처치한 시점이다. 다른 던전 클리어나 중도 귀환으로 달성되지 않는다.
- 회색쥐 처치는 수락 이후 플레이어 또는 동료가 처치한 수를 누적한다. 여러 탐험에 걸쳐 누적하며 중도 귀환·패배가 이미 기록한 처치를 취소하지 않는다. 강화된 회색쥐도 같은 종류로 센다.
- 아이템 납부는 현재 플레이어 소지품의 쥐 꼬리를 사용한다. 수락 전부터 보유한 아이템도 납부할 수 있다. 미정산 전리품은 소지품이 아니므로 탐험 정산에서 정가에 구매하여 보관해야 한다.
- 납부 의뢰는 보고 시 요구 수량을 차감하고 보상을 지급한다. 부족하면 보고할 수 없으며, 단순 카드 선택이나 수락은 아이템을 소비하지 않는다.
- 구조 노드는 수락한 미달성 의뢰에 대해 대상 던전·층에만 추가된다. 기존 지도 정의를 변경하지 않고 이번 탐험의 지도에 양방향 선으로 연결한다. 입장 즉시 일반 회색쥐 전투가 시작되고 승리하면 구출 안내를 표시한다.
- 구조 노드의 재방문은 새 전투나 구출을 발생시키지 않는다. 이미 구출을 달성했거나 의뢰를 보고한 뒤 새로 던전에 입장하면 구조 노드가 생기지 않는다. 전투에서 패배하거나 구조 전에 귀환하면 다음 입장에서 재도전할 수 있다.
- 구조되는 모험가들은 이번 단계에서 설정상 구조 대상이며 기존 6명 인물을 소환하거나 자동 영입하지 않는다.
- 의뢰 보상은 플레이어에게 금화로 지급한다. 예시 보상은 던전 클리어 100, 납부 40, 구조 80, 처치 50금화다. 기존 탐험 전리품 분배와 별개다.
- 수락·진척·보고·보상은 저장 후에만 확정한다. 의뢰 진행 저장 실패 시 전투와 탐험을 멈추고 안내 창을 닫아 재시도한다. 중복 입력이나 재시도로 목표·아이템·금화가 중복 적용되지 않는다.
- 수락 상태·진척·완료 기록은 게임 재실행 후에도 유지한다. 탐험 중 위치와 전투 상태를 저장하는 기능은 추가하지 않는다.

## 조정 시트

위치: `Assets/1_InternalTools/Util/DataSheetLoader/Table/`.

| 시트 | 내용 |
| --- | --- |
| QuestDefinitionTable | 의뢰 ID·이름·설명·종류·대상 던전/층/아이템/적·요구량·보상 |
| QuestRescueNodeTable | 구조 노드 이름·설명·아이콘·좌표·연결 지점·적 수 |
| QuestTextTable | 카드·진척·수주·보고·오류·구출 안내 문구 |

변경 내용은 다음 씬 초기화 때 읽는다. 실행 경로와 검증은 [의뢰 구조](../Architecture/Quests.md)에 기록한다.
